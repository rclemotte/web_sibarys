# Web de Sibarys

Sitio estático (HTML + CSS + JS, sin build) de Sibarys Transporte Corporativo.

- `index.html` — Inicio
- `servicios.html` — Servicios
- `styles.css` — estilos (dorado, negro, gris y blanco)
- `app.js` — menú en celular, pestañas de flota y servicios, formulario → WhatsApp
- `img/` — fotos y logo

Para activar WhatsApp: completar la constante `WHATSAPP` al inicio de `app.js`
(formato internacional sin `+`, ej. `595981123456`).

Deploy: Vercel, sin configuración (Framework: Other).
